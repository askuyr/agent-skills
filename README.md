# Agent Skills — мероприятие, афиши, печать, соцсети

Семь навыков для агентных ассистентов (OpenCode, Claude Code, Codex — формат `SKILL.md` с YAML-frontmatter). Все написаны под реальную работу: организация форумов, афиши, документы к печати, креативы для соцсетей.

Правило каждого навыка — не «вдохновляющие советы», а проверяемые шаги и чек-лист: что считать, где смотреть, что отдать на выходе.

## Навыки

|---|---|---|

## Установка

```bash
git clone https://github.com/askuyr/agent-skills.git
```

Скопировать нужные папки в каталог навыков агента:

| Агент | Каталог |
|---|---|
| OpenCode (глобально) | `~/.config/opencode/skills/` |
| OpenCode / общий для агентов | `~/.agents/skills/` |
| Claude Code | `~/.claude/skills/` |

Перезапустить агент. Каждый навык — одна папка с `SKILL.md`, других зависимостей нет.

```bash
cp -r agent-skills/skills/* ~/.agents/skills/
```

## Как устроен навык

```markdown
---
name: event-program
description: Программа и тайминг мероприятия. Использовать на «собери программу форума», ...
---

# Программа мероприятия

## 0. Источник правды
...
```

- `description` содержит формулировки, на которых навык должен срабатывать, — это единственное, что агент видит до загрузки;
- тело — процедура с проверками и разделом «Ограничения»;
- личные пути не зашиты: `$env:USERPROFILE` вместо конкретного пользователя.

## Совместимость

- Формат `SKILL.md` (YAML frontmatter + markdown) — стандарт Agent Skills.
- `smm-design-check` и `svg-assets` используют встроенный браузер агента (`browser.*`) для проверки результата; без него дают ручной чек-лист.
- Windows-специфика есть в `desktop-cleanup` (PowerShell), остальные навыки кроссплатформенные.
