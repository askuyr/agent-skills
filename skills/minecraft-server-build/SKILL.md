# Minecraft Server Build

Сервер для 2–5 друзей, а не админ-стенд. Простота важнее «правильности».

## Порядок

1. **Инвентаризация.** Что уже стоит: папка `C:\mcserver` (может отсутствовать — тогда создаём), версия Java (`java -version`), jar, мир, `server.properties`, логи в `logs/`. Не переустанавливать существующее. Если пользователь ранее сказал «удали всё» — не воссоздавать молча, уточнить.
2. **Java.** Java 21+ (для новых версий — 25). Проверить `JAVA_HOME` и что сервер стартует этой Java.
3. **Сервер.** Paper — если нужны плагины и производительность; Fabric — если нужен модпак. Скачать актуальный jar, переименовать `paper.jar`/`fabric-server-launch.jar`, `eula.txt` → `eula=true`.
4. **Мир.** Из архива: распаковать во временную папку, найти корень по `level.dat` (+ папка `region`), сделать бэкап текущего мира в `backup\world_old_<дата>`, скопировать корень в `C:\mcserver\<WorldName>`.
5. **Конфиг.** `server.properties`: `white-list=false`, `online-mode=true` (если не ломает скины), `max-players` 5–10, `view-distance` 8–10, `motd` по вкусу. Сложные права (LuckPerms, TPA-запросы) — не ставить.
6. **Моды.** `.mrpack` с Modrinth: распаковать и разложить `overrides/` + список модов в `mods/`. Проверять совместимость лоадера и версии игры.
7. **Сеть.** Radmin VPN вместо проброса портов: сеть Radmin, IP `26.x.x.x`, порт `25565`. Проверить, что сервер слушает `0.0.0.0`.
8. **Запуск и проверка.** Стартовый скрипт с адекватным `-Xmx`, дождаться `Done (…s)!`, зайти самому, проверить мир, скины, инвентари, телепорт.
9. **Друзьям.** Архив с модами + инструкция: версия, лоадер, установщик, адрес Radmin, куда распаковать.

## Предпочтения пользователя (не переоткрывать)

- Никаких GUI-панелей и веб-админок.
- Белый список выключен; «просто чтобы пахало, пофик на проверки модов».
- Никаких плагинов 18+ — не устанавливать и не предлагать.
- `/tp` доступен всем без запросов.
- Проброс портов на роутере не нужен, если работает Radmin.

## Риски

- Смена лоадера/версии на существующем мире ломает инвентари и постройки → сначала бэкап, потом эксперимент.
- Плагины «на всякий случай» ломают вход друзьям; ставить минимум.
- Пиратские версии и `online-mode=false` — предупредить о последствиях, не включать молча.
