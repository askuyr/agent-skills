# Continue Work

Пользователь возвращается после обрыва контекста и ждёт продолжения, а не нового старта.

Если в проекте есть контекстные коммиты, историю решений быстрее вытащить скиллом `recall`, чем перечитывать код. Разделение: `recall` — когда просят только сводку/историю, этот скилл — когда просят продолжать работу.

## Порядок

1. **Собрать состояние, не спрашивая.**
   - `git status`, `git log -n 5 --stat`, `git diff --stat`
   - последние изменённые файлы (`git log -1 --name-only`), наличие `TODO`/`STATUS`/`README` с планом
   - живой адрес (dev/прод) — открыть и посмотреть, что реально работает
2. **Восстановить решения прошлых сессий.** Если в истории есть контекстные коммиты — вытащить их action-строки:
   `git log --all --grep="intent(" --grep="decision(" --grep="rejected(" --grep="constraint(" --grep="learned("`
   Это отвечает на «почему так», не перечитывая код.
3. **Определить точку обрыва.** Что уже сделано, что сломано, что не проверено. Отличить «написано» от «проверено в браузере/на сервере».
4. **Продолжить, не переделывая.** Запрещено заново устанавливать уже установленное (Java, сервер, зависимости), переписывать рабочие файлы «с нуля» и удалять существующие папки. Использовать то, что создано.
5. **Довести до проверяемого результата.** Правка → проверка → коммит+пуш, если проект под git.
6. **Короткий отчёт:** «было / сделано сейчас / следующий шаг». Без пересказа всего брифа.

## Правила

- Максимум один короткий блок уточнений, и только если без него можно сломать данные.
- Повторная отправка того же сообщения — тот же запрос: не повторять уже выполненные шаги.
- Ровно один главный следующий шаг в отчёте, а не меню из десяти.
- Если бриф содержит противоречия с текущим кодом — верить коду и сказать об этом.
- Не выдумывать, что «всё готово»: писать, что проверено, а что нет.
- Ответ — по-русски.

## Признаки, что работа идёт неправильно

- Агент начинает install/setup с нуля при существующей папке проекта.
- Задаёт вопросы, ответы на которые есть в `git log` или в файлах.
- Отчитывается «готово» без открытия страницы/запуска сервера.
