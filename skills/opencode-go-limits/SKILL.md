# OpenCode Go Limits

Лимиты Go — **месячная сумма в долларах на каждую модель отдельно**, а не общий пул. Внутри неё окна: 5 часов = 20%, неделя = 50%, месяц = 100%. Когда окно выбрано, запросы к этой модели блокируются (или уходят в Extra Usage, если он включён).

## Как считать

```powershell
python scripts/usage.py
```

Полезные варианты:

```powershell
python usage.py --plan go-plus          # go | go-plus | go-teams
python usage.py --model deepseek-v4.1-flash
python usage.py --json                  # машинный вывод
python usage.py --warn                  # код возврата 2 при >=80% любого окна
```

План по умолчанию берётся из `config.json` рядом со скиллом (`{"plan": "go"}`). Если пользователь говорит «я на Go Plus» — сразу `--plan go-plus` и предложить поправить `config.json`.

## Что делает скрипт

1. Открывает локальную базу `~/.local/share/opencode/opencode.db` **только на чтение** (`mode=ro` + `PRAGMA query_only`): ничего не пишет, боевую сессию не блокирует, путь можно задать через `--db` или `$OPENCODE_DB`.
2. Берёт сообщения ассистента с `providerID = opencode-go`, суммирует токены `input / output+reasoning / cache.read / cache.write`.
3. Считает стоимость по опубликованному прайсу Go, с учётом peak/off-peak у DeepSeek (peak: 01–04 и 06–10 UTC, пн–пт).
4. Сравнивает с лимитами плана из `references/limits.json` за скользящие 5 часов, 7 дней и текущий календарный месяц.

## Приватность

- Никакого сетевого кода: скрипт не ходит в интернет и ничего не отправляет — все цифры (прайс, лимиты) лежат в `references/limits.json`.
- Из базы берутся только счётчики токенов и ID модели. Текст сообщений, промпты, ответы и вывод инструментов не печатаются, не сохраняются и не пересылаются — даже в `--json`.
- База не изменяется: подключение read-only, любая попытка записи падает с ошибкой.
- Если базы нет по ожидаемому пути — скрипт пишет «database not found» и выходит с кодом 1, ничего не создавая.

## Как читать вывод

| Поле | Смысл |
| --- | --- |
| `5h` | расход в текущем 5-часовом окне против 20% месячного лимита |
| `week` | скользящая неделя против 50% |
| `month` | текущий месяц против 100% |
| `mo %` | доля месячного лимита модели |

Пороги: **80% любого окна** — предупредить и предложить перейти на другую модель или бесплатную; **95%** — считать, что модель почти заблокирована. `unl` — безлимитная бесплатная модель.

## Правила

- Лимит — **на модель**: исчерпанный DeepSeek не мешает Kimi или GLM. Не писать «квота кончилась», если кончилась одна модель.
- Локальный расчёт — оценка по токенам. Точное значение — `opencode.allowance` в ответах API и страница [console](https://opencode.ai/console). Если расчёт и консоль расходятся, верить консоли и сказать об этом.
- Не выдумывать остаток: если в базе нет сообщений Go за период, так и написать («локальных данных нет»), а не «0% использовано».
- Не менять план, не включать Extra Usage и не отзывать ключи без явной команды.
- Окна скользящие: после паузы 5-часовое окно освобождается само, месячное — с началом календарного месяца UTC.
- Модели вне прайса (новые) скрипт пропускает и перечисляет отдельно — тогда сказать, что для них нужна запись в `references/limits.json`.

## Обновление данных

Прайс и лимиты — снимок `https://opencode.ai/docs/go` от 2026-11-01. При изменении тарифов обновить `references/limits.json`: блок `plans.<plan>.limits_usd` и `pricing_per_million`. Модель, которой нет в прайсе, не считается — добавлять в оба блока.
