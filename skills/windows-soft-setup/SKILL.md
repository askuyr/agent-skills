# Установка софта на Windows

Ставит программу и останавливается. Соседние шаги (настройка, твики, удаление) — только по отдельной просьбе.

## Проблема, которую решает

В истории агент ставил софт и уезжал дальше: правил конфиги «запрета», чистил провайдеров, лез в автозагрузку. Пользователь останавливал: «стоп я просил только скачать», «так стоп», «Windhawk только делаем». Одна просьба = одно действие.

## Порядок

1. **Уточнить одно:** папка установки. Если названа (`Desktop\курсо\cursor`, `Desktop\Новая папка`) — ставить туда, создать папку заранее. Не названа — обычное место, не спрашивать.
2. **Выбрать способ по убыванию:**
   - `winget install --id <Id> -e --accept-package-agreements --accept-source-agreements` — для Cursor, Python, Java, Steam, браузеров. Поиск: `winget search <имя>`.
   - Портативный архив (zip/7z) — распаковать в целевую папку, ярлык не создавать без просьбы.
   - Установщик `.exe` — тихие флаги: `/S`, `/silent`, `/VERYSILENT /NORESTART`. Если тихих флагов нет, а папка важна — сказать об этом, а не молча ставить в Program Files.
3. **Проверить установку:** файл `.exe` на месте, `--version` / `-version` отвечает. Для Java/Python — что команда видна в новом шелле, `PATH` не ломать.
4. **Отчёт:** путь, версия, чем проверено, что осталось сделать руками (перезапуск, вход в аккаунт, выбор скина/языка).

## Отдельные случаи

- **Сборки и моды (Minecraft/Prism).** Скачивать в папку на рабочем столе, архив собирать так, чтобы друг импортировал одним файлом; версия Java — под версию игры. Дальше — скилл `minecraft-server-build`.
- **Обход блокировок (zapret/Flowseal).** Ставится отдельной папкой, конфиг правится только для названных приложений («нужен только телеграм десктоп»), службы и автозапуск — по явной просьбе.
- **Кастомизация интерфейса (Windhawk, темы).** Только сам инструмент и названный мод; чужие твики не добавлять.
- **Аналоги платного софта (Office, KMS).** Искать официальные бесплатные аналоги (LibreOffice, OnlyOffice), а не активаторы. Пиратские сборки не скачивать и не запускать: это малварь и нарушение лицензии.
- **Игры из Steam/лаунчеров.** Не ломать файлы игры; язык и настройки — через лаунчер, файлы править только если лаунчер не даёт.

## Жёсткие правила

- Ничего не удалять и не «оптимизировать» без просьбы.
- Не менять провайдеров, конфиги других программ, автозагрузку и реестр в той же задаче.
- Скачанное из интернета — проверять источник (официальный сайт/репозиторий), не запускать `.exe` из случайных архивов.
- Ответ — по-русски.
