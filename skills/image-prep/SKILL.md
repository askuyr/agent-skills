# Подготовка изображений

Картинка готовится под конкретное место: мм печати или px экрана. Всё остальное — «примерно».

## 0. Арифметика, которая экономит переделку

При 300 dpi (печать):

| Формат | Пиксели |
|---|---|
| Фото 3×4 см | 354×472 |
| Бейдж A6 105×148 мм | 1240×1748 |
| A4 | 2480×3508 |
| A3 | 3508×4961 |
| A2 | 4961×7016 |

Для экрана: 1× размер слота, ретине хватает 2×. Герой-баннер — не шире 1920 px.

Правило: **не апскейлить**. Если исходник меньше нужного — сказать «нужно фото не меньше 354×472, это 180×240, будет мыло» и попросить оригинал, а не растягивать.

## 1. Кадрирование

- Лицо: глаза на верхней трети, макушка не обрезана, плечи в кадре.
- Стороны не искажать: `resize` с сохранением пропорций + `crop`, а не «заполнить рамку» наугад.
- Для 3×4 оставлять запас по краям: печать и обрезка съедают 1–2 мм.
- Квадрат 1:1 — центр по лицу, не по геометрии кадра.

## 2. Формат и вес

- Печать: JPEG качество 90–95 или PNG, **sRGB**, без прозрачности под фото.
- Веб: WebP (лучше) или JPEG q80, цель ≤ 300 КБ для баннера, ≤ 100 КБ для карточки.
- Прозрачный фон — только PNG/WebP; для логотипов и иконок.
- Удаление фона: только когда фон реально ровный; на волосах и тенях — не «магической палочкой», иначе видно кайму.

Pillow (если установлен `python -m pip install pillow`):

```python
from PIL import Image
im = Image.open(src).convert("RGB")
im = im.resize((354, 472), Image.LANCZOS)   # после кропа под 3:4
im.save(dst, "JPEG", quality=92, dpi=(300, 300))
```

Инструмент не важен — важен результат: нужный размер в пикселях, sRGB, без апскейла.

## 3. Вставка в документ или макет

- В DOCX — в рамку фиксированного размера, «Обрезка → Заполнить», а не растягивание мышью.
- В HTML — `img` с `width/height` и `object-fit: cover`; отдельный файл под 2×, если важно качество.
- Замена картинки в готовом макете: сохранить пропорции слота, не двигать текст и сетку, новый файл, старое имя не переиспользовать.

## 4. Проверка

1. Размер в пикселях ≥ расчётного для слота.
2. Открыть при 100%: нет мыла, нет полос от JPEG на градиентах.
3. Цвет кожи не уехал в зелень/красноту (sRGB, не CMYK-профиль).
4. Вес файла в пределах для веба, если картинка идёт на сайт.
5. Имя: `<что>_<размер>_<назначение>.<ext>` (`Фото_3х4_300dpi.jpg`, `banner-hero_1920.webp`).

## Ограничения

- Не пересохранять JPEG повторно «на всякий случай» — каждое сохранение теряет качество.
- Оригиналы не перезаписывать: обработанная версия — новый файл.
