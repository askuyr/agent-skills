# Афиша → Figma

Афиша живёт в двух местах: **UI-кит в Figma** (источник правды) и **отдельный HTML-файл** под рендер. Киты — база: без них не начинать.

## 0. Правило файлов (обязательное)

Одна афиша = один файл: `afisha_<номер>_<стиль>.html` + `.png` + `.pdf`. Каждый вариант, формат (A3, сторис, квадрат) и каждая правка — новый файл. Готовый файл не перезаписывать.

## 1. UI-кит (делается один раз, живёт в Figma)

Страница `Kit` в файле афиш:

- фреймы форматов: A3 297×420 мм, A2, сторис 1080×1920, квадрат 1080×1080;
- цветовые стили по ролям: `bg`, `fg`, `accent`, `muted` (не «синий 1», «синий 2»);
- текстовые стили: `H1`, `H2`, `kicker`, `body`, `caption` с реальными шрифтами;
- компоненты блоков: шапка, программа/расписание, гость, низ с контактами и QR;
- сетка 12 колонок, 4–5 мм жёлоб.

Палитру и шрифты даёт `brand-identity-kit`, проверяют `better-colors` / `better-typography`.

## 2. Афиша (HTML)

Делать по скиллу `folio` (раздел posters, 4 уникальных варианта, `render.py`). В CSS брать те же цвета и шрифты, что в ките, именами ролей: `--bg`, `--accent`, `--h1`. Показывать 4 варианта, один уходит в Figma.

## 3. Перенос в Figma (от быстрого к полному)

1. **TalkToFigma MCP** (лучший: нативные слои + инстансы компонентов кита). Figma plugin `cursor-talk-to-figma-mcp-plugin` + websocket-сервер; инструменты `create_frame`, `create_text`, `create_rectangle`, `create_component_instance`, `set_fill_color`, `export_node_as_image`. Ставится вручную: `bun` (сейчас не установлен), `bun socket`, плагин в Figma, `join_channel`.
2. **html.to.design** (Figma community, плагин divRIOTS) — импорт готового HTML-файла в Figma редактируемыми слоями. Без кода, платно на больших страницах.
3. **SVG-импорт** (запасной) — вектора правятся, но текст становится контурами. Годится только для графики, не для текста.

Figma Dev Mode MCP (`http://127.0.0.1:3845/mcp`, уже прописан в `opencode.jsonc`) — только чтение кита и макетов; писать слои им нельзя. Включается в Figma: Preferences → Enable Dev Mode MCP Server.

## 4. Проверка результата в Figma

- текст — текстовые слои, а не картинка и не outline;
- цвета и шрифты совпадают с китом;
- фрейм = точный формат, метки/QR векторные;
- блоки — инстансы компонентов кита (если перенос через TalkToFigma).

## Ограничения

- TalkToFigma не привязывает цвет к стилю кита — после переноса выделить слои и применить стили вручную (или через плагин).
- Экспорт `export_node_as_image` с PNG отдаёт base64 текстом.
