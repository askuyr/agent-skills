# Яндекс Форма для мероприятия

Форма — часть мероприятия, а не отдельная железка: дата, адрес, название и оформление берутся из афиши, чтобы не разъезжались.

## 0. Источник правды

Название, дата, время, адрес, дедлайн регистрации — берутся из последней афиши/программы (`afisha_*.html` в папке мероприятия), а не придумываются заново. Если афиши нет — спроси дату, адрес и дедлайн одной строкой.

## 1. Структура формы

Минимум, который нужен организатору:

1. ФИО — обязательно
2. Организация / вуз — обязательно
3. Должность — необязательно
4. Телефон — обязательно
5. Email — обязательно
6. Город — необязательно
7. Формат участия: очно / онлайн — обязательно
8. «Как узнали о форуме» — необязательно
9. Согласие на обработку персональных данных — обязательно (152-ФЗ), ссылка на политику

Дальше — только то, что реально спросят: питание, сопровождающий, мастер-класс по выбору. Каждый лишний вопрос снижает число регистраций.

Тексты вопросов — по `better-writing`: короткий вопрос, понятный пример в подсказке, без канцелярита.

## 2. Создание формы

Форму создаёт человек в `forms.yandex.ru` (у агента нет доступа к аккаунту). Отдай готовый пакет, чтобы он вставил:

- заголовок формы = название мероприятия + «регистрация»;
- описание = дата, время, адрес одной строкой;
- список вопросов с типами (короткий текст / список / несколько вариантов / телефон / email / дата);
- тексты кнопки («Зарегистрироваться») и экрана «спасибо» — там повтор даты, адреса и что взять с собой.

После создания попроси ссылку на форму и подставь её дальше. Ссылку не выдумывать никогда.

## 3. Оформление под афишу

Тема Яндекс Формы настраивается слабо, поэтому бренд живёт в обёртке:

- страница-обёртка (`form_<мероприятие>.html`) в стилистике афиши: шапка с названием и датой, форма в iframe по центру, подвал с адресом;
- цвета и шрифты — те же CSS-переменные, что в афише (`--bg`, `--accent`, `--h1`);
- в самой форме выбрать максимально близкую тему, загрузить обложку из афиши;
- кнопка «Зарегистрироваться» на сайте/в посте ведёт на обёртку, а не на голую форму.

Одна форма = один файл обёртки, как с афишами.

## 4. Проверка перед публикацией

- пройти форму самому на телефоне (375 px) и на десктопе;
- обязательные поля и согласие реально блокируют отправку;
- экран «спасибо» содержит дату, время и адрес;
- ссылка открывается без авторизации в Яндекс;
- дедлайн стоит в тексте формы, а не только в афише.

## 5. После мероприятия

Выгрузка ответов в XLSX из самой формы (Ответы → Экспорт), сводка: сколько зарегистрировалось, очно/онлайн, города, организации. Файл кладётся в папку мероприятия, не на рабочий стол.

## Ограничения

- Аккаунт Яндекса, тема и права доступа — только у пользователя; агент готовит тексты, структуру, обёртку и проверку.
- iframe с формой может не грузиться при открытии файла через `file://` — проверять через локальный сервер или после публикации.
