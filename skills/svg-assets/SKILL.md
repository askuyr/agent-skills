# SVG-ассеты

Один набор — одна система: палитра, сетка и типографика из бренд-кита, разные форматы вокруг неё.

## 0. Палитра и шрифт

Цвета и шрифты — из `brand-identity-kit` или из UI-кита афиши. В каждом SVG — только эти значения, без «похожего синего». Прозрачный фон обязателен: ассет кладут на разные подложки.

## 1. Форматы

| Файл | Размер | Где живёт |
|---|---|---|
| `banner-header.svg` | 1200×630 | превью ссылки, шапка сайта |
| `banner-social.svg` | 1200×1200 | пост в соцсети |
| `banner-story.svg` | 1080×1920 | сторис |
| `card-speaker.svg` | 1080×1080 | карточка спикера, имя + должность |
| `logo-krv-horizontal.svg` | по контенту | знак + название в строку |
| `logo-mark.svg` | 1:1 | только знак |

`viewBox` — в пикселях, `width/height` не «на глаз», края выровнены по модулю (8 px).

## 2. Текст в SVG: где ломается

- `<text>` с `font-family` остаётся **текстом** в Figma только если этот шрифт есть в системе/Figma. Иначе Figma покажет замену шрифта.
- Если важна точная геометрия (логотип, надпись в узком блоке) — текст в контуры через `<path>`.
- Правило: **логотип — контуры, баннеры — `<text>`**, чтобы их можно было править.

Не врать про drag-and-drop: SVG всегда импортируется вектором, но живой текст — только с доступным шрифтом. Проверять на импорте, а не обещать.

## 3. Сборка

1. Сетка: 8 px модуль, отступы 48/32/16.
2. Безопасная зона: текст не ближе 5% от края (сторис обрезают сверху/снизу).
3. Контраст текста ≥ 4.5:1 к подложке — проверить `better-colors`, а не на глаз.
4. Все элементы — в одном `<svg>`, без вложенных внешних файлов и `xlink` на растр.
5. Имена файлов — как в таблице; версия — новым файлом, старое не перезаписывать.

## 4. Проверка

```
browser.tabs.open({ url: 'file:///C:/.../banner-header.svg' })
browser.screenshot({ tabID })
```

- открыть каждый SVG в браузере на своём размере, посмотреть глазами;
- уменьшить до 25%: знак читается, мелкий текст — нет (значит, мелкий текст лишний);
- в Figma импортировать один файл и проверить: вектор, текст, цвета;
- в конце — список файлов и что в каждом.

## Ограничения

- Анимацию и CSS-фильтры в SVG не использовать: Figma их не сохраняет.
- Шрифты не встраивать в SVG как base64 — файл распухает и Figma его не любит.
