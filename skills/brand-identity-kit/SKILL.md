# Brand Identity Kit

Айдентика для малого бренда (одежда, услуги, личный бренд) без выдуманных «исследований».

## Порядок

1. **Бриф из того, что уже сказано.** Категория, аудитория, ценовой сегмент, тон. Не устраивать длинное интервью.
2. **Нейминг.** 10–15 вариантов в 2–3 направлениях; сразу отсекать занятые (поиск, домены `.ru`/`.com`, товарные знаки). Подавать списком с одной строкой смысла на вариант.
3. **Знак.** Сначала словесное описание идеи, потом SVG. Строгая роскошь (Bentley/Rolls-Royce/Rolex) — геометрия, монограмма, тонкие линии; не мультяшные формы. Обязательно: масштабируемость, версии в один цвет, отступы, минимальный размер.
4. **Палитра.** 4–6 цветов с HEX/RGB и ролями (фон, текст, акцент, линии). Тёмная и светлая подача.
5. **Типографика.** Только свободные лицензии (OFL/Google Fonts) с указанием названия и источника. Пары: заголовочный + текстовый, правила размеров и трекинга.
6. **Слоган и брендбук.** Короткий слоган + объяснение для заказчика на 6 строк: кто мы, для кого, чем отличаемся.
7. **Мокапы.** Реалистичные JPEG (упаковка, визитка, вывеска), если просили «красивые», а не SVG.
8. **Шрифты в систему.** Скачать в папку проекта, установить в Windows (копия в `%LOCALAPPDATA%\Microsoft\Windows\Fonts` + запись в реестр либо ПКМ → «Установить»), перезапустить Figma — иначе шрифт не появится.
9. **Сдать файлы.** В папке проекта: `logo/` (SVG, PNG), `fonts/`, `palette.png`, `brandbook.md`/PDF.

## Правила

- Не использовать шрифты без свободной лицензии в публичных макетах; проверять лицензию, а не «вроде бесплатный».
- Не выдавать сгенерированные нейросетью фото за реальные товары.
- Название не считается свободным без проверки домена и поиска; «звучит хорошо» — не аргумент.
- Тексты для заказчика — без англицизмов ради англицизмов, если бренд русскоязычный.

## Быстрый разбор картинки «что за цвета и шрифт»

1. Взять пипеткой 5–8 доминирующих цветов (включая фон и линии).
2. Определить класс шрифта: антиква/гротеск, контраст, засечки, наклон, ширина.
3. Назвать 2–3 ближайших свободных аналога и дать ссылку на источник.
4. Для точных шрифтов из макета — искать по характерным буквам (`R`, `a`, `g`, `t`), а не по общему ощущению.
