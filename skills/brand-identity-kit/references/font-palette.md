# Шрифты и палитра: практика

## Свободные шрифты (OFL / Google Fonts)

| Роль | Варианты |
| --- | --- |
| Заголовки, строгая роскошь | Prata, Playfair Display, Cormorant Garamond, Bodoni Moda |
| Заголовки, современный гротеск | Inter Tight, Manrope, Unbounded, Onest |
| Текст | Inter, Onest, Source Serif 4, Lora |
| Акциденция/монограмма | Cormorant SC, Forum |

Правила: проверять `OFL.txt` в архиве шрифта; не брать «free for personal use» в коммерческий проект.

## Установка шрифта в Windows

```powershell
$src = "C:\путь\fonts\Prata-Regular.ttf"
Copy-Item $src "$env:LOCALAPPDATA\Microsoft\Windows\Fonts\" -Force
New-ItemProperty -Path "HKCU:\Software\Microsoft\Windows NT\CurrentVersion\Fonts" `
  -Name "Prata (TrueType)" -Value "Prata-Regular.ttf" -PropertyType String -Force
```

Затем полностью закрыть и открыть Figma. В Figma Desktop шрифт подхватывается из системы; в браузерной версии — только после перезапуска вкладки.

## Разбор палитры со скриншота

1. Фон, основной текст, акцент, вторичный акцент, линии/рамки — минимум 5 значений.
2. Проверить контраст текста к фону (WCAG AA: 4.5:1 для тела).
3. Проверить, нет ли «грязных» оттенков из-за JPEG-артефактов: брать цвет из крупной однородной области.
4. Записать в таблицу: HEX, RGB, роль, где применяется.

## Определение шрифта по картинке

- Засечки: форма (брусковая/волосная), наклон оси, контраст штрихов.
- Гротеск: закрытость апертуры (`C`, `S`), форма `a` (одно- или двухэтажная), `t` и `l` с хвостами.
- Проверять характерные пары: `Rg`, `fi`, `1/7`, цифры и кавычки.
- Итог: класс + 2–3 аналога + уверенность (высокая/средняя/низкая). Не выдавать догадку за факт.
