# Печатные документы

Печать прощает меньше, чем экран: тут важны миллиметры, а не «примерно так».

## 0. Размеры, которые нужны чаще всего

| Что | Размер | Примечание |
|---|---|---|
| Афиша A2 | 420×594 мм | + вылеты 3 мм с каждой стороны |
| Афиша A3 | 297×420 мм | + 3 мм вылеты |
| Программа A4 | 210×297 мм | поля ≥ 15 мм |
| Бейдж | 105×148 мм (A6) | отверстие/зажим сверху, имя крупно |
| Удостоверение | 2 разворота по 65×95 мм | фото 3×4 см слева |
| Грамота / благодарность | A4 горизонт | рамка не ближе 10 мм к краю |

Правила: 300 dpi для растровых картинок, мелкий текст ≥ 8 pt, безопасная зона 5 мм от края под обрез.

## 1. Работа с шаблоном DOCX

- Шаблон не перезаписывать: копия `бейдж_<мероприятие>.docx`, оригинал остаётся.
- Фото вставлять через «Обрезка → Заполнить» в рамку 3×4 см, а не растягивать мышью: пропорции лица не должны ломаться.
- Плейсхолдеры (`[ФИО]`, `[ДОЛЖНОСТЬ]`) заменять реальными данными; если данных нет — оставить видимый плейсхолдер, а не пустое место.
- Проверить: шрифт не подменился, кириллица не уехала, перенос строки в длинной должности (2 строки максимум).

## 2. DOCX → PDF

Word: «Сохранить как» → PDF, опция «Стандарт (публикация в интернете и на печати)».

Без Word (LibreOffice):

```powershell
& "C:\Program Files\LibreOffice\program\soffice.exe" --headless --convert-to pdf --outdir "<папка>" "<файл.docx>"
```

PDF проверять перед отправкой: размер страницы в мм (не «A4 примерно»), шрифты встроены, картинки не мыльные.

## 3. Макет афиши в печать

- HTML/PDF отдавать в мм, не в px: `@page { size: 420mm 594mm; margin: 0 }`.
- Вылеты 3 мм: фон и картинка выходят за обрез, текст — нет.
- Чёрный текст — 100% K, не «богатый чёрный» из четырёх красок.
- QR — минимум 2×2 см, с белым полем вокруг, проверить сканирование с экрана и с распечатки.

## 4. Чек-лист перед печатью

1. Размер и ориентация совпадают с заказом (A2 ≠ A2 с полями).
2. Поля и безопасная зона: ничего важного ближе 5 мм к краю.
3. Все фото 300 dpi, без апскейла из превью.
4. Дата, время, адрес, дедлайн — сверить с афишей и программой, не с памятью.
5. Шрифты встроены, спецсимволы (— « » №) не квадратами.
6. Имя файла: `<что>_<мероприятие>_<размер>_<дата>.pdf`.
7. Тестовая печать одной страницы на обычном принтере: масштаб 100%, не «по размеру страницы».

## 5. Партия документов (бейджи, грамоты на 50 человек)

- Данные берутся из выгрузки формы (`yandex-form-event`) → таблица → генерация по шаблону.
- Генерация скриптом (Python + `python-docx` или слияние в Word), а не 50 копий руками.
- После генерации: открыть 2–3 случайных файла из партии и проверить, что ФИО и организация попали в свои места.
- Ошибка в шаблоне = 50 испорченных бланков, поэтому сначала один пробный, потом партия.

## Ограничения

- Не печатать «на глаз»: если размер неизвестен — спросить, а не угадывать.
- Цветопробу и плотность бумаги выбирает человек; макет только готовится к ним.
